# DAB Entry Formatter

This tool allows you to tune single-entry formatting for a Dictionary App Builder (DAB) project created from a
FieldWorks (FLEx) XHTML export, without hand-writing CSS. See [DESIGN.md](DESIGN.md) for what
it does and how; [CLAUDE.md](CLAUDE.md) for the DAB/FLEx facts it's built on.

## How to use it

You only need one file: **[dab-entry-formatter.html](dab-entry-formatter.html)**. Download it
and open it in **Chrome or Edge** (double-click it, or drag it into a browser window).

1. Click **Choose DAB project folder…** and pick the folder that directly contains your
   project's `.appDef` file — e.g.
   `…\Documents\App Builder\Dictionary Apps\App Projects\<Your Project>`.
2. Your browser will ask for permission to read (and later write) that folder — allow it. This
   all happens locally in your browser; nothing is uploaded anywhere.
3. If the project has more than one exported dictionary (say, a reversal index alongside the
   main one), you'll be asked which one to tune.
4. **Tune.** Adjust the numbers in the Fields table and the globals bar — indent, wrap indent,
   line height, sense-number outdent, and so on — and watch the preview on the left update
   instantly against a real entry from your project. Use the Previous/Next buttons or the Find
   box to check other entries as you go.
5. Keep an eye on the **Generated rules** table underneath the preview. If anything shows up in
   amber/red, DAB won't actually apply that row when the app is built — click any text in the
   preview to filter the table down to the rules affecting just that text.
6. When you're happy, click **Save to live appDef**. It writes straight into your project's live
   `.appDef` and turns on "Modify Single-Entry Styles" if it wasn't already. The first save for a
   project automatically backs up the pre-tuning appDef as
   `<name> (backup before dab-entry-formatter).appDef`, so you always have a way back.
7. Close and reopen the project in DAB to see the result.

**Firefox and Safari** can load and tune a project too, but lack the browser API needed to save
directly — use the **Copy .appDef styles** button instead and paste the result into a copy of
your appDef by hand.

## Building the tool from source

`dab-entry-formatter.html` is generated by `dab-entry-formatter.py` — you only need the `.py`
file if you want to modify the tool itself. With Python 3 installed:

```
python dab-entry-formatter.py
```

This (re)writes `dab-entry-formatter.html` next to it. No dependencies beyond the standard
library.
